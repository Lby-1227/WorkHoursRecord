# 工时记录 2.0.0 · Rust＋GPUI Kit

Windows x64 桌面工时应用。使用 GPUI Kit 0.9.0 默认后端及官方 Rust MCP SDK rmcp 3.9.0，依赖由 Cargo.lock 锁定，不依赖 .NET 或 WebView。此程序与原 WPF 版本独立，不导入旧版授权、缓存或领取状态。

## 软件下载

[下载 Windows x64 运行包](https://github.com/Lby-1227/WorkHoursRecord/releases/latest/download/WorkHoursRecord-win-x64.zip) · [查看版本与更新说明](https://github.com/Lby-1227/WorkHoursRecord/releases/latest)

下载后解压，双击 `WorkHoursRecord.exe`。首次使用需在系统浏览器连接本人钉钉账号和正确组织。源码下载需要自行构建，运行包可直接运行。

## 使用

1. 运行 `dist\WorkHoursRecord.exe`，首次进入“设置配置”。
2. 点击“连接钉钉”，在系统浏览器完成本人账号、正确组织的独立 OAuth 授权。成功读取真实记录后进入主界面。
3. 主界面查看今日工时、周期总工时、工作日/周末工时、每日累计加班和两条宝箱任务。
4. “每日打卡统计”上方显示工时趋势，下方显示秒级打卡时间、扣休、分钟、小时及核对状态。空缺日期不补零。
5. 点击“悬浮模式”切换到右上角 368×224 逻辑像素卡片。“主界面”按钮返回。卡片标题可拖动，图钉切换置顶。
6. 关闭窗口或卡片上的“—”隐藏到托盘。单击托盘图标恢复当前模式，右键可切换主界面/悬浮、刷新或退出。

每次重新启动进入主界面，自动恢复本应用授权。程序只允许一个 Rust 实例；WPF 版不受影响。正常退出使用侧栏或托盘中的“退出”。

## 连接与数据

固定服务为官方“钉钉考勤”（市场 ID 9668）：

- [官方配置网页](https://aihub.dingtalk.com/#/mcp-market/mcp)
- MCP 地址：`https://mcp-gw.dingtalk.com/oauth/server/attendance`
- 只调用 `get_personal_attendance_records`、`query_check_record`、`query_check_result`。

“配置链接”打开官方网页，不需要粘贴令牌或授权码。授权使用服务发现、动态客户端注册、PKCE S256 和本机回环回调，凭证由当前 Windows 用户的 DPAPI 加密保存。后台授权失效只提示重新连接，不自动弹出浏览器。重新交互授权创建新的数据分区；普通重启与刷新沿用原分区。

启动、手动刷新、跨日及周期切换同步当期历史；默认每5分钟同步今日，每分钟更新本地计时。同一时间只同步一轮，普通同步总超时30秒，交互授权最多5分钟。网络预检约10秒。官方网页或网关无法访问时，应先恢复本机对钉钉站点的正常 HTTPS 访问。

同步失败会保留已有快照、冻结计时并禁止领取；成功后用真实记录校准。收到真实下班卡后停止增长，并减回同步延迟期间多计的部分。多段、跨日或无法唯一核对的记录显示“待核对”，不自行拼接。记录按日期替换，不重复累计。

## 工时与宝箱

- 北京时间，每月25日至次月24日，包含首尾；25日自动开始新周期。
- 周一至周五只扣打卡区间与12:00—13:00实际重合的午休。
- 周末按原始跨度：超过10小时扣120分钟，否则超过6小时扣60分钟，两档不叠加。
- 每天先扣实际休息，再舍去不足一分钟，最后汇总并换算小时。
- 工作日累计加班为逐日 `max(净分钟−480, 0)` 之和，不扣未来工作日，也不以短工时抵消。
- 总净工时（含周末）严格大于250/280/320小时，对应300/500/1000；精确到整数分钟时需15001/16801/19201分钟。
- 工作日加班达到30/50/70小时，对应500/1000/1500。同类只计最高档，两类相加，最高估算2500。
- 每类显示首个未领取宝箱；达标才可本地领取，领取后显示下一档。重复点击和重启不重复领取，更正后保留领取记录并重新判断达标状态。
- 总工时每日预测按剩余自然日分摊，包含周末；加班预测按剩余周一至周五分摊。今天未下班包含今天，已下班从明天算，向上取整到分钟。

宝箱只是本地目标记录，不关联公司奖金发放。

## 外观与本地文件

设置中的不透明度范围为20%—100%，只改变悬浮卡背景；文字、图标和按钮保持清晰。释放滑块保存，重启保留设置。主窗口不受透明度影响。

本应用数据位于 `%LOCALAPPDATA%\WorkHoursRecordRustGpui`，包含加密凭证、配置、窗口位置、按身份/周期隔离的考勤快照和领取记录。损坏文件会明确报错，不自动清空领取记录。发布包不包含此目录的个人数据。

## 构建与验证

环境：Windows x64、Rust MSVC 工具链及 Visual Studio C++ 构建工具/Windows SDK。本次使用 rustc 1.99.1。项目级 `.cargo/config.toml` 使用 rsproxy 依赖源及静态 CRT，不修改系统设置。

在工程目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Build.ps1
```

脚本使用 `--locked`，运行全部自动化测试，再构建发布程序、更新 `dist` 和运行压缩包。构建前请退出正在运行的此 Rust 版本，避免 exe 被占用。`artifacts\tests.log` 为测试日志，`artifacts\test-results.json` 为测试结果。

`examples\audit.rs` 只读本应用已有真实快照，输出不含凭证和本人 ID 的联调报告；它不发起网络请求，不代替完整性验证或现场下班验收。详细结果见随包的“验证结果.md”（源码目录为 `docs\验证结果.md`）。
