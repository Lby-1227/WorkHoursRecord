# 测试与验证说明

本仓库提供 Rust 源码、Cargo.lock、资源及构建脚本。授权凭证和实际考勤记录保存在运行应用的 Windows 用户目录，不随源码发布。

## 自动化测试

```powershell
cargo test --release --target x86_64-pc-windows-msvc --locked --all-targets -- --test-threads=1
```

测试覆盖工时和扣休边界、每月25日周期切换、累计加班、宝箱顺序领取、每日目标、重复/缺卡/多段、分页完整性、身份核对、OAuth PKCE和令牌刷新、Windows窗口布局与透明背景。

公开版周期汇总测试使用人工构造的工作日和周末样本。协议测试使用本机隔离服务及明确的测试凭证，不连接个人钉钉账号。

Windows布局测试创建隐藏窗口，核对三页1100×780及独立悬浮卡368×224。当前GPUI Kit Windows包装层的像素回读支持有限，绘制场景检查不等同于完整桌面视觉验收。

## 真实服务验收

每位使用者需要在系统浏览器完成本人钉钉账号与组织的独立OAuth。服务授权、网络、Schema及组织权限影响真实读取，离线测试通过不能保证某个账号能够访问所有考勤记录。

真实联调应核对身份、历史分页完整性、今日上班计时、实际下班后的停表与延迟回扣。个人联调结果保留本机，不上传此仓库。
